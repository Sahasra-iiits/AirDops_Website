# 🎧 Airdopes Website

A simple **frontend-only Airdopes-inspired website** built using **React** and **Tailwind CSS**. This project was created mainly for **practice and learning**, focusing on UI design, subtle animations, and responsive layouts.

## 🚀 Live Demo

🔗 **Live Website:** https://air-dops-website.vercel.app/

## ✨ Features

- ⚛️ Built with **React**
- 🎨 Styled using **Tailwind CSS**
- ✨ **Subtle UI animations** for a smoother experience
- 📱 **Responsive design** (still open for improvements and suggestions!)
- 🎧 Clean and modern **Airdopes-inspired landing page**

## 🛠️ Tech Stack

| Technology             | Usage              |
| ---------------------- | ------------------ |
| React                  | Frontend framework |
| Tailwind CSS           | Styling            |
| Motion / Framer Motion | Animations         |

## 🎯 What I Learned

- Creating layouts with **Tailwind CSS**
- Working with **responsive breakpoints**
- Adding **smooth animations** to React components
- Structuring a small frontend project from scratch
- Using **AI as a learning assistant** to better understand responsive design concepts and implementation approaches
